## Key Conventions

### Config Loading
- **Always** load _gsane/config.yaml first — it defines {user_name}, {communication_language}, {output_folder}
- If config is already in session context, **never reload it** — use the cached values
- {project-root} resolves to the workspace root at runtime

### Governance Rules
- **Delivery Contract Mandatory**: Dev agents write NO code without a formal Delivery Contract generated by the Master.
- **TDD Enforcement**: Code logic and its coverage tests are shipped concurrently.
- **Zero-Touch Fix-Loop**: The pipeline runs ash gsane.sh validate. QA bounces exits back to Dev internally until Exit 0. Humans are only notified on success.
- **Solo Trip Wire**: When making systemic file rewrites, invoke the team unSubagent to coordinate. "Don't ask to deliberate, coordinate the deliberation then act."
