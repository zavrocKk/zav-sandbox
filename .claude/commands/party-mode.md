# Party Mode — Brainstorming multi-agents

Lancer une validation collective avant un changement GSANE significatif.

## Instructions

1. Lire le workflow : `_gsane/workflows/party-mode/workflow.md`
2. Sujet du brainstorming : $ARGUMENTS
3. Phase 1 — Huddle ciblé : scorer les agents par pertinence au sujet
4. Phase 2 — Brainstorming : chaque agent vote APPROVE / BLOCK / CHALLENGE / ABSTAIN
5. Phase 3 — Planning : produire un execution-plan si le consensus mène à une action

## Règles

- Consensus : ≥2 APPROVE pour continuer
- ≥2 BLOCK pour arrêter
- Conflit (1 APPROVE + 1 BLOCK) : escalade vers Master
- Langis ne vote pas — il arbitre
